# CalcIt

CalcIt is a RESTful calculator application built with Java, Spring Boot and Maven.

## Planned Features

- Addition, subtraction, multiplication and division REST endpoints
- Input validation and structured error responses
- Unit and integration testing with JUnit 5
- Multi-stage Docker containerization
- Docker Compose deployment with Nginx
- Automated CI/CD using Jenkins and GitHub
- Container image publishing to Docker Hub

## Current Status

Phase 1: Project initialization and build setup.

## Build and Test

```bash
./mvnw clean package
./mvnw test
```
